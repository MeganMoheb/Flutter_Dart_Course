Smeg Store Flutter App
A modern and sleek Flutter application that showcases kitchen appliances like fridges, kettles, microwaves, and blenders in a structured UI. The app includes a horizontal scroll of categories, a searchable product list, and navigation to cart and profile screens.



![image alt][https://github.com/MeganMoheb/Flutter_Dart_Course/blob/80295f3fcf2be76babde1afe6a95a81f81b48457/flutter_practice/smeg-project/Screenshot%20(479).png]



Features
🏠 Home Screen with gradient header and search bar

🔍 Horizontal category scroller with product icons

📦 Product list view showing name, description, image, and price

🛒 "Add to Cart" button with dummy navigation to Cart page

👤 Profile and Cart pages via bottom navigation bar

🎨 Consistent custom color styling using Color.fromARGB(255, 7, 30, 48)
